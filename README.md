I enjoy taking projects from initial design to implementation, integrating services, modeling data, and building software that addresses real-world needs.

- **Full-Stack Development:** Angular, React, Next.js, and API integration.

- **Current Goal:** Looking for a junior Software Engineer opportunity where I can contribute to real products and grow alongside an engineering team.

- **Availability:** Immediately available for full-time opportunities.

## Featured Work

### AI Copilot — Enterprise Knowledge Assistant

Developed during my end-of-studies internship at ALTEN, this project combines microservices and a Retrieval-Augmented Generation pipeline to support question answering over internal documents.

- Designed and implemented backend services using Java and Spring Boot.
- Integrated a Python-based RAG service for document retrieval and LLM-powered responses.
- Implemented role-based document access and source-grounded answers.
- Worked across authentication, document management, conversation workflows, and service integration.

*The project was developed for an internal enterprise context; confidential implementation details are not disclosed.*

### Sounds of Morocco — Music and Culture Platform

An independently developed platform dedicated to Moroccan electronic and traditional music artists.

- Built and deployed a full-stack web application.
- Worked across frontend development, content management, data integration, and deployment.
- Used Next.js, Tailwind CSS, Strapi, PostgreSQL/Supabase, and cloud hosting services.

### Job Hunter — Search Aggregation Tool

A Python-based application for collecting and organizing job search results.

- Integrated SerpApi for search result collection.
- Implemented relevance scoring and duplicate handling.
- Stored search data and history using PostgreSQL.
- Added spreadsheet exports and a lightweight web interface.

[Explore the repository](https://github.com/ELGHAD/job-hunter)
